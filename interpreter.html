知識庫 0 筆 命中 0 / 0 離線示範模式 語言自動偵測
讓顧客對著手機說話 不限語言。系統自動判斷顧客說哪一國話，同時顯示原文與中文；查得到就直接用他的母語回答，查不到就請你用中文回一次，之後它就記住了。

顧客模式：顧客說任何語言都可以，系統會自動判斷並用同一種語言回答。

設定

金鑰只存在這支手機的瀏覽器裡，不會上傳。與後台管理系統共用同一組設定。

留空則進入離線示範模式：只比對關鍵詞，僅內建幾句示範翻譯可用。
注意：若此頁是用 Claude Artifact 連結開啟，外部 API 呼叫會被瀏覽器安全政策阻擋，AI 模式無法運作。要用 AI 模式請改開 GitHub Pages 網址或本機檔案。
語言不需要事先設定。頂端語言選單保持「自動偵測」時，顧客說哪一國話，系統就用哪一國話回答；需要固定成某一種語言時才手動指定。
